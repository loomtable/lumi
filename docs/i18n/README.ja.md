# Lumi by Loomtable

**あなたの Mac の中にある光。**

尋ねれば、Lumi が暗がりの中から見つけ出し、作業をこなし、答えを見せてくれます。

どのアプリを使っていても、キーを 1 回タップして声で尋ねるか、2 回タップして入力します。Lumi はその瞬間に画面に表示されているものだけを見ます。見るのは前面のウィンドウ、選択中のテキスト、localhost のポートの背後にあるリポジトリ、ターミナルのフォルダなどです。そのうえで、質問をあなたがすでにセットアップしたエージェントに渡します。エージェントはあなたのログイン、MCP サーバー、CLAUDE.md、スキルを使って、ファイルを探し、Mac 上で作業し、あなたがつないだツールを使います。答えは短い音声の一言で返り、図があると分かりやすいときはカードが付きます。Lumi が提案する変更は、あなたの OK を待ってから実行されます。

**画面の上で、あなたの声を聞く。· ファイルを見つけ、扱う。· あなたがつないだツールと連携する。· 無料、ローカル、オープンソース。**

あなたの仕事のために作りました。創業者、デザイナー、アナリスト、ライター、学生、開発者、そしてその間にいるすべての人のために。

- **Web サイト:** [lumi.loomtable.com](https://lumi.loomtable.com)
- **ダウンロード:** [最新リリース](https://github.com/loomtable/lumi/releases/latest)（DMG。[インストール](#インストール)を参照）
- **価格とライセンス:** 無料、GPL-3.0
- **開発:** [Loomtable](https://loomtable.com)（AI ネイティブなプロダクトスタジオ）。Powered by Claude。

## 必要なもの

- Apple Silicon（M1 以降）を搭載した macOS 26。Intel Mac と古いバージョンの macOS には対応していません。
- Lumi が質問を渡すエージェント。バージョン 2.1.312 以降を、インストールしてサインインした状態で用意してください。名称はこのページの最後にまとめています。
- メモリは 16 GB を推奨します。8 GB の場合、多くのアプリを開いていると答えが遅くなることがあります。

## 使い方

1. Lumi キー（デフォルトは右 ⌥、つまり right Option）をタップして質問します。もう一度タップすると送信されます。話している間キーを押し続ける方法もあります。入力したいときはダブルタップします。
2. Lumi は目の前にあるもの（下記参照）を見て、質問をあなたのエージェントに渡します。
3. 一言の答えが音声で返ります。図があると分かりやすいときは、見ていたものの横にカードが表示されます。カードは Esc を押す、別の場所をクリックする、アプリを切り替える、のいずれかで閉じます。

質問はまず Quick で、高速なモデルが扱います。ファイル、コマンド、ブラウザが必要な質問の場合、Quick はより強力なモデルの Deep に引き継ぎ、引き継いだことをあなたに伝えます。

- 質問の頭に「go deep」と付けると、最初から Deep で答えます。
- 「research」と付けると、時間のかかるバックグラウンドジョブを開始します。

各レーンのモデルとルーティング（Auto、Always Quick、Always Deep）は Settings › Models で設定します。

答えはあなたのために組み立てられます。一言の答えに、役立つときは図を添え、正確な場所をリングで示します。長文は返しません。Lumi は答えのある場所を指し示します。

## 見るものと送るもの

Lumi が画面を見るのは、あなたが呼び出したときだけです。そのとき読み取るのは次のものです。

- 前面にあるアプリとウィンドウ
- 選択中のテキスト、ポインタの下にある要素、フォーカス中のフィールドが編集可能かどうか
- 前面のアプリが表示している内容（Lumi が判別できる場合）
  - ターミナルのフォルダとコマンド
  - ローカル開発サーバーのポートとフォルダ
  - エディタのプロジェクトとファイル
  - チャットのチャンネルとスレッド
  - Finder のフォルダと選択項目
- 最近使ったアプリと、ディスプレイの配置
- 前面ウィンドウ、またはディスプレイのスクリーンショット

パスワードマネージャーと、Settings › Privacy でブロックしたアプリは見ません。それらのウィンドウはスクリーンショットにも写りません。パスワードフィールドのテキストも読み取りませんが、フィールドに表示される伏せ字の点はスクリーンショットに写ることがあります。コマンドラインやアドレスに含まれるトークンやキーなどの秘密情報は、送信前に取り除かれます。

あなたの質問、このコンテキスト、スクリーンショットは **あなた自身のエージェント** に渡ります。エージェントはあなたの Claude アカウントのもとで、それらを Anthropic に送って答えを得ます。

Lumi 自体がインターネットに接続するのは、次の場合だけです。

- 音声をオンにしたとき、小さな無音検出器（約 1 MB）を Hugging Face から 1 回だけダウンロードします。
- オンボーディングまたは Settings › Voice で選んだ場合に限り、Parakeet 音声認識（約 466 MB）または Kokoro の音声（約 437 MB）を Hugging Face からそれぞれ 1 回だけダウンロードします。
- ElevenLabs の音声をオンにした場合、返答のテキストが読み上げのために ElevenLabs に送られます。

Settings › Connections で追加した MCP サーバーは、あなたのエージェントの中で動きます。ほかの MCP サーバーと同じように、それぞれ自分のサービスと通信します。

**音声とスクリーンショットの扱い**

- デフォルトでは、Lumi は Mac 標準の音声認識と音声で聞き取り、話します。大きなダウンロードは不要ですが、初回に macOS が英語の音声ファイルを追加することがあります。
- 音声認識と、ElevenLabs 以外のすべての音声は Mac 上で動作します。あなたの声の録音が Mac の外に出ることはありません。
- スクリーンショットは最大 24 時間 Mac に保存されます。Settings › Privacy で 6 時間または 1 時間に短縮できます。

**トレースログ**

- デフォルトではオフです。
- オンにすると、タイミング、イベントの種類、結果を記録し、7 日間保持します。
- あなたが話したことや見たものは記録しません。

## インストール

Lumi は GitHub Releases で DMG として配布しています。Mac App Store と Homebrew にはまだありません。

1. [Releases ページ](https://github.com/loomtable/lumi/releases/latest)から `Lumi-<version>.dmg` と `Lumi-<version>.dmg.sha256` をダウンロードします。ダウンロードを検証するには、2 つのファイルを保存したフォルダで `shasum -a 256 -c Lumi-<version>.dmg.sha256` を実行します。
2. ディスクイメージを開き、Lumi を「アプリケーション」にドラッグします。
3. Lumi はまだ Apple Developer ID で署名されていないため、macOS は初回の起動を止めます。次の手順で開きます。
   1. Lumi を一度開き、警告を閉じます。
   2. システム設定 › プライバシーとセキュリティ を開き、下にスクロールします。
   3. Lumi の横にある **このまま開く**（Open Anyway）をクリックします。
   4. パスワードまたは Touch ID で確認します。

   以降、Lumi は普通に開きます。 <!-- OWNER: macOS 26 日本語版での「システム設定 › プライバシーとセキュリティ」と「このまま開く」の表記を実機で確認 -->

   ターミナルに慣れていれば、次のコマンドでも同じことができます（このアプリにだけ適用されます）。
   ```sh
   xattr -dr com.apple.quarantine /Applications/Lumi.app
   ```
4. オンボーディングに沿って、Lumi キー、アクセス権、音声を設定します。

アップデートするときは、[Releases ページ](https://github.com/loomtable/lumi/releases/latest)から新しいリリースをダウンロードし、「アプリケーション」の Lumi を置き換えます。設定、会話、アクセス権はそのまま残ります。

## アクセス権

Lumi はオンボーディングで次のアクセス権を求めます。それぞれ、システム設定の該当する場所が開きます。 <!-- OWNER: macOS 26 日本語版での各項目名を実機で確認 -->

- **入力監視**（Input Monitoring、必須）: Lumi キーを検知するためです。入力した内容を Lumi が記録することはありません。
- **アクセシビリティ**（Accessibility、必須）: 選択範囲の読み取り、テキストの挿入、Esc でのカードの終了に使います。
- **画面収録**（Screen Recording、必須）: 質問と一緒に送るスクリーンショットのためです。
- **マイク**（Microphone、任意）: 声で尋ねるためです。なくても、いつでも入力で尋ねられます。

macOS は、入力監視と画面収録のアクセス権を Lumi の再起動後に反映します。それぞれの横にある Quit & Reopen ボタンを使ってください。

## ソースからビルドする

```sh
Scripts/make-dev-cert.sh   # 初回のみ: 安定した署名 ID を作成し、再ビルド後もアクセス権が保たれるようにする
Scripts/build-app.sh       # ビルド、署名し、/Applications/Lumi.app にインストール
open -a Lumi
```

- `make-dev-cert.sh` は、証明書をコード署名用に信頼させるため、ログインパスワードを 1 回だけ尋ねます。
- 初回ビルドでは、`make-dev-cert.sh` が作成した開発用の鍵を codesign が使ってよいか尋ねられることがあります。「常に許可」を選んでください。
- `INSTALL=0 Scripts/build-app.sh` を使うと、インストールせずに `dist/Lumi.app` をビルドします。
- テストは `Scripts/test.sh` で実行します。
- アプリアイコンには Xcode（`actool`）が必要です。Xcode がない場合は汎用アイコンでビルドされます。

Lumi は必ず「アプリケーション」、Spotlight、Finder から開いてください。ターミナルからは開かないでください。ターミナルから起動したコピーは、ターミナルのアクセス権を借りてしまいます。

## アンインストール

1. エージェント側に残る Lumi の会話記録も消したい場合は、先に削除します。Conversations で、各会話の Forget を使ってください。これらの記録は `~/.claude/projects/` に、あなた自身のセッションと混ざって保存されています。
2. メニューバーのメニューから Lumi を終了し、`/Applications/Lumi.app` をゴミ箱にドラッグします。
3. データを削除します。
   ```sh
   rm -rf ~/Library/Application\ Support/com.loomtable.lumi   # 会話、レポート、音声モデル、プラグインのコピー
   rm -rf ~/Library/Application\ Support/Loomtable/Lumi       # 保存された接続トークン
   rm -rf ~/Library/Caches/com.loomtable.lumi                 # スクリーンショット
   rm -rf ~/Library/Logs/com.loomtable.lumi                   # トレースログ
   rm -rf ~/Library/HTTPStorages/com.loomtable.lumi           # ネットワークキャッシュ（ある場合）
   rm -rf ~/.cache/fluidaudio/Models/kokoro                   # 音声の発音データ
   defaults delete com.loomtable.lumi                         # 環境設定
   ```
4. ElevenLabs のキーを追加した場合は、キーチェーンアクセスを開いて `com.loomtable.lumi.elevenlabs` を検索し、削除します。
5. Settings › Connections で MCP サーバーを追加した場合は、`claude mcp list` で一覧を表示し、`claude mcp remove --scope user <name>` でひとつずつ削除します。
6. 任意: システム設定 › プライバシーとセキュリティ の各リストで Lumi を選び、− をクリックします。

## Lumi が加えるもの

| 今使っているもの | Lumi が加えるもの |
| --- | --- |
| ターミナルで使うエージェント | 同じエージェントを、どのアプリからでも使えます。キー 1 つとあなたの声、そして前面のウィンドウがコンテキストになります。スクリーンショットを貼ったり、今どこで何をしているかを説明したりする必要はありません。 |
| AI への質問に使うチャットアプリ | 別のアカウントや別の記憶ではなく、あなた自身のセットアップ（リポジトリ、CLAUDE.md、MCP サーバー、スキル）から答えます。答えは、見ているものの横に表示されます。 |
| 一日中画面を記録するアシスタント | Lumi はキーを押したときだけ画面を見ます。スクリーンショットが Mac に残るのは最大 24 時間です。 |

## よくある質問

**Lumi とは何ですか？**
無料でオープンソースの macOS メニューバーアプリです。どのアプリでもキーをタップして、声か入力で尋ねます。あなた自身のエージェントが画面の内容を使って答え、Lumi が短い答えを読み上げます。図があると分かりやすいときはカードを表示します。

**Lumi は無料ですか？**
はい。Lumi は GPL-3.0 の無料オープンソースソフトウェアです。質問はあなた自身のエージェントを通して処理されるため、あなたの Claude プランまたは API の利用量に含まれます。

**何が必要ですか？**
Apple Silicon を搭載した macOS 26 の Mac と、バージョン 2.1.312 以降をインストールしてサインインしたエージェントです。名称はこのページの最後にあります。Lumi は Mac 上でそのエージェントを動かします。Lumi 独自のログインやサーバーはありません。

**Lumi は Anthropic が作ったものですか？**
いいえ。Lumi は Loomtable が作っています。あなたのエージェントを通して Claude で動作しますが、Anthropic が作ったものではなく、Anthropic とは提携していません。

**Lumi は何を、どこに送りますか？**
あなたの質問、前面のアプリから読み取ったコンテキスト、スクリーンショットがあなたのエージェントに渡り、エージェントが Anthropic に送って答えを得ます。Lumi にはサーバーもアナリティクスもありません。詳しくは[見るものと送るもの](#見るものと送るもの)を参照してください。

**Lumi は常に画面を見ていますか？**
いいえ。Lumi キーを押したときだけ見ます。パスワードマネージャーと、Settings › Privacy でブロックしたアプリは対象外です。

**話さずに使えますか？**
はい。Lumi キーをダブルタップすれば入力できます。マイクのアクセス権は任意です。

**Lumi はファイルを変更したり、コマンドを実行したりできますか？**
Lumi はあなたのエージェントを通して作業します。Mac 上での読み取り、実行、編集ができ、あなたがつないだツールも使えます。Lumi が提案する変更は、あなたの OK を待ちます。挿入したテキストが勝手に送信されることはありません。Lumi があなたの代わりにメールやメッセージを送ることもありません。

**Intel Mac、古い macOS、Windows、Linux で動きますか？**
いいえ。Lumi には Apple Silicon を搭載した macOS 26 が必要です。

**オフラインで使えますか？**
いいえ。音声認識とデフォルトの音声は Mac 上で動作します。ただし、答えはあなたのエージェントを通して Claude から届くため、インターネット接続が必要です。

**初回起動を macOS が止めるのはなぜですか？**
Lumi はまだ Apple Developer ID で署名されていないためです。一度開いてから、システム設定 › プライバシーとセキュリティ で **このまま開く**（Open Anyway）をクリックしてください。詳しくは[インストール](#インストール)を参照してください。
