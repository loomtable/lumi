Rate limits

Limits apply per API key. Requests over the limit return 429 Too Many Requests with a Retry-After header in seconds.

PlanRequests / secondBurstRequests / day
Free204010,000
Starter60120250,000
Team2004002,000,000
EnterpriseCustom — contact sales

Burst is the most requests accepted in any single second, as long as your average over the last 10 seconds stays within the per-second limit.

Daily limits reset at 00:00 UTC. Batch endpoints count as one request per call, regardless of the number of messages.
